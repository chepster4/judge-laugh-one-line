## The line

> **I bought noise-cancelling headphones to finally hear myself think, and now all I can hear is how loudly I chew.**

The setup promises silence for deep thought; the punchline breaks it —
the silence only amplifies something worse: my own chewing. One everyday
observation, no stock joke, no pun, no flooded smart-home topic, and the
laugh lands on the last words.

## How to run

Requires Node 22 or later. No dependencies.

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (UTF-8, 111 characters,
no trailing newline).
